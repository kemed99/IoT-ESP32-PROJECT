# Kelas C - ESP32-S3 IoT Project

Folder ini berisi *source code*, dokumentasi, dan konfigurasi untuk proyek IoT ESP32-S3 yang dikembangkan oleh Kelas C.

## 📌 Status Progress

Berikut adalah rekapitulasi progres terbaru dari pengembangan proyek di Kelas C berdasarkan riwayat repositori:

* **Implementasi Firmware & Sistem:** Telah ditambahkan file `main.rs` di dalam direktori `src/` yang berisikan implementasi untuk dashboard AromaLab.
* **Konfigurasi Environment:** File `.env` telah berhasil dikonfigurasi dan ditambahkan ke dalam direktori `tools/` untuk menyimpan pengaturan *environment* sistem.
* **Desain & UI Dashboard:** *Preview* antarmuka dashboard telah diunggah dalam bentuk gambar (`tampilan dahsboard iot_page-0001.jpg`), dan aset gambar dashboard juga telah ditambahkan ke dalam direktori `docs/`.
* **Laporan Dokumentasi:** Dokumen `REPORT_IoT_Progress_5A.pdf` telah dilampirkan sebagai kelengkapan laporan proyek.
